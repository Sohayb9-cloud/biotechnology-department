# University of Samarra — Department of Biotechnology

Static bilingual (English/Arabic) website for Visual Studio Code + GitHub Pages.

## Identity
University of Samarra
College of Applied Sciences
Department of Biotechnology

## Included
- Home
- About
- Curriculum
- 16 subject pages
- Faculty (maintainable, no invented names)
- Laboratories (maintainable, no unverified permanent list)
- Research
- Graduation Projects
- News
- Gallery
- Contact
- Local scientific SVG illustrations
- Arabic/English language switcher
- Responsive design
- robots.txt / sitemap.xml / 404.html / .nojekyll

## Run in VS Code
Open this folder in VS Code and use Live Server, or open `index.html` directly.

## GitHub Pages
1. Create a public repository.
2. Upload the contents of this folder so `index.html` is at repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save, then wait for the Pages build.
5. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` with your GitHub username.

## Accuracy note
The site uses official University of Samarra sources for institutional history and public profile. The 16-subject overview is the subject set supplied for this project. The University's Bologna policy document describes a broader four-year program with 49 modules; therefore exact semester placement and module codes should be taken from the approved Bologna curriculum.
